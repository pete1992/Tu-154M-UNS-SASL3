Back Box decoder file format.

Files for Black Box should have extension ".bbox". All other extensions are ignored

File format for Black Box is fairly simple. It is a plain text, that reads line by line inside the app. Every line should start with a number, that defines, what this line contains. 
All data is divided by "\t" (TAB) symbol. It should also be present at the end of a line.
Line numbers are:
	0 - date and flight number in format DD_MM_YY_NNN - Date_Month_Year_flightNumber
	1 - Names of the data. Used to create tables inside the app and to show them as a list of parameters
	Notice, that first five datas should always be: 
		Simulator time as numbers in seconds. Used to build charts
		ZULU or Local time in format HH:MM:SS, used to show as time stamps below the charts
		Latitude in format DD.ddddd - coordinates, used to draw a map
		Longtitude in format DD.ddddd - used to draw a map
    True course
	2 - Data units, like degrees, percents, ratio and so on. Used to write them next to parameters names in the list
	3 - Data limits in format NN/NN. Used to draw a chart in red color, when data numbers are out of those limits. If numbers are the same, like 0/0 - limits are ignored.
	4 - Data group name. It's a text names of the groups, to draw similar data on the same chart. For example Engine RPM #1, Engine RPM #2 and Engine RPM #3 can have the same group as "Engine RPM"
		Groups names are also the names of the charts on screen.
	9 - The data itself as float point numbers.
