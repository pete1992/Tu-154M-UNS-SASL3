# Mechanical audio sources

Derived from the local Tu-154B2-CE-master v1.41-dev Custom Sounds/new_snds assets.
Stereo 16-bit PCM is averaged to mono for SASL3 positional audio; sample rates are preserved.
Positions use the M cockpit OBJ pivots/attachment offsets and main gear positions.
M has fixed seat frames: only its existing armrest and door motion receives movement audio.
